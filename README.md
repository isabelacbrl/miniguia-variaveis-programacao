# Miniguia: Variáveis e Conceitos Básicos de Programação

## Contexto

Este projeto foi desenvolvido como parte de um desafio da DIO, com o objetivo de utilizar Inteligência Artificial como ferramenta de apoio aos estudos.

O tema escolhido foi "Variáveis e conceitos básicos de programação", por ser fundamental para quem está iniciando na área de tecnologia.

---

- Entender o que são variáveis
- Compreender o que são valores
- Aprender conceitos básicos da programação

## Engenharia de Prompts

### Prompt 1:
O que são variáveis na programação?

**Resposta resumida:**
Variáveis são espaços na memória usados para armazenar dados.

---

### Prompt 2:
Explique variáveis de forma simples, como se fosse para iniciantes

**Resposta resumida:**
Variáveis funcionam como caixas onde guardamos informações.

---

### Prompt 3:
Qual a diferença entre variável e valor?

**Resposta resumida:**
Variável é o espaço, valor é o conteúdo dentro dela.

## Miniguia de Estudo

### O que são variáveis?

Variáveis são espaços onde armazenamos informações para usar depois.

### O que são valores?

Valores são os dados que ficam dentro das variáveis, como números ou textos.
